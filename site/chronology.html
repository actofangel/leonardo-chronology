This site is a working research platform as well as a publication. Records can be entered before they are verified. Each record carries two independent labels. The evidence layer says what kind of claim it is: documented, scholarly dating or tradition. The review status says how far this site has checked it.

Review statuses

Pending
Entered, not yet checked. This is the default.
Flagged
Pending, with a recorded reason for caution. Derived from the flags field.
Disputed
A concrete doubt or a proposed correction exists, and it is not yet settled.
Corrected
The record was changed after review. The history says what changed.
Verified
Checked against at least one source of an admitted type.
Not accepted
Set aside by the researcher. Kept visible, shown in grey.

Rules

  1. Admitted source types are critical edition, catalogue raisonné, manuscript study, monograph and archival publication. Web pages, model recall and AI generated text can raise a flag or propose a change. They cannot verify. A record marked verified without an admitted source is shown as pending, and the checks report it.
  2. A correction is recorded under proposed and is not applied to the record until a person accepts it. Accepting means editing the base data, setting the status to corrected and adding a history line.
  3. History lines are added, never edited or removed.
  4. New records go in extra.json, with a lane and the same fields as existing records. They start as pending.
  5. The automated checks run on every load. A failing check blocks nothing, but it stays visible until fixed.

Files

The records are in the page. Reviews and extra records are separate files published beside it, so they can be updated without touching the page. Each published version is kept, which gives an audit trail.

reviews.json
{
  "schema": "ldv-chronology-reviews/1",
  "updated": "2026-10-09",
  "reviews": {
    "record-id": {
      "status": "pending | verified | disputed | corrected | rejected",
      "flags": ["Reason for caution."],
      "note": "Optional note.",
      "proposed": { "date": "text", "start": 1499.25 },
      "sources": [
        { "type": "edition | catalogue | ms_study | monograph |
                   archive_publication | web | model_recall | other",
          "cite": "Full citation with page or document number.",
          "url": "Optional." }
      ],
      "history": [ { "at": "2026-10-09", "by": "name", "note": "What was done." } ]
    }
  }
}

extra.json
{ "schema": "ldv-chronology-extra/1",
  "records": [ { "lane": "works", "id": "w-example", "title": "...", "kind": "...",
                 "start": 1500, "end": 1501, "date": "...", "tier": "D | S | T",
                 "place": "...", "text": "...", "basis": "..." } ] }

Scope. This chronology records documents, dated or datable works, and attested relationships. It does not include the project's working hypotheses, such as the Apollonius circle in the Last Supper or deliberate Latin lexical overlap, which belong on a separate hypothesis layer.
